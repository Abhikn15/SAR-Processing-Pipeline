# SAR Processing Pipeline

A reproducible Synthetic Aperture Radar (SAR) processing and training repository designed for classroom demonstrations, student practicals, and research workflows.

## Project Objectives

- Build a structured SAR processing environment on Ubuntu
- Work with Sentinel-1 and other SAR datasets
- Develop reproducible Python-based SAR workflows
- Integrate command-line and desktop SAR processing tools
- Maintain professional documentation and version control
- Create portfolio-ready SAR projects and practical exercises

## Repository Structure

```text
SAR_Project/

├── docs/            # Documentation and practical guides
